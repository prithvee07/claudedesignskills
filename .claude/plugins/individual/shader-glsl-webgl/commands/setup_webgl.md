# /shader-glsl-webgl-setup_webgl

GLSL Shaders - Setup Webgl

## Description

Executes the setup_webgl script for GLSL Shaders.

## Usage

```bash
/shader-glsl-webgl-setup_webgl
```

## Implementation

This command runs the `setup_webgl.py` script from the GLSL Shaders skill, which provides automated assistance for setup webgl.

## Notes

- This command leverages the skill's built-in automation scripts
- For interactive mode, the script will prompt for required information
- Check the skill documentation for detailed script usage
