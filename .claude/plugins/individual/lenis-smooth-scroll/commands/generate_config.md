# /lenis-smooth-scroll-generate_config

Lenis Smooth Scroll - Generate Config

```bash
/lenis-smooth-scroll-generate_config
```

This command runs the `generate_config.py` script from the Lenis Smooth Scroll skill, which provides automated assistance for generate config.
